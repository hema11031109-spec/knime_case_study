This project focuses on analyzing customer churn using the Customer Churn dataset in KNIME Analytics Platform. The main objective is to identify customers who are likely to leave the company and understand the factors influencing customer churn.

🎯 Objectives
Analyze customer churn patterns.
Identify customers who are likely to leave.
Understand the factors affecting customer retention.
Gain insights to improve customer satisfaction.

🛠️ Tools & Technologies
KNIME Analytics Platform
Customer Churn Dataset
Data Analytics
Machine Learning

Dataset Import
Data Cleaning and Preprocessing
Exploratory Data Analysis
Data Visualization
Customer Churn Analysis
Model Building and Prediction (if performed)

Analyzed customer churn patterns.

Explored customer behavior and retention trends.
